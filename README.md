# PyGeoModel Documentation Site

React + Vite site for the PyGeoModel package landing page and documentation page.

Public site:

- https://mplebron.github.io/PyGeoModel-docs/

## Development

```bash
npm install
npm run dev
```

Routes:

- `/PyGeoModel-docs/` landing page on GitHub Pages
- `/PyGeoModel-docs/docs` documentation page on GitHub Pages

## Build

```bash
npm run build
```

The build script writes both `dist/index.html` and `dist/404.html` so the `/docs` route can be opened directly on GitHub Pages.
